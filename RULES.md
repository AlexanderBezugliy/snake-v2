# Project: Snake Web Pro (Technical Specification & Rules)

## 1. Core Philosophy & Applied Skills
При разработке и рефакторинге этого проекта агент обязан строго применять следующие установленные навыки:
- **`frontend-design`**: Полный отказ от шаблонных решений. Использовать продвинутые техники CSS, сложные многоуровневые тени, качественную работу со слоями (Glassmorphism) и выраженный **Digital-стиль**. Визуал должен выглядеть современно и "дорого".
- **`canvas-design`**: Максимальное использование возможностей Canvas API. Продвинутый рендеринг, система частиц, glow-эффекты и математически точная интерполяция движений.
- **`polish`**: Доведение до идеала всех микроинтеракций. Использование кастомных `cubic-bezier` для анимаций, бесшовные переходы состояний.

## 2. Tech Stack & Architecture
- **Engine:** HTML5 Canvas API (игровой цикл через `requestAnimationFrame`).
- **UI:** Modern HTML5 / CSS3 (CSS Variables, Flexbox/Grid). Никаких тяжелых фреймворков.
- **Logic:** Vanilla JavaScript (ES6+, модульная структура или четкое разделение классов).
- **Storage:** LocalStorage для сохранения State и High Scores.

## 3. UI States (Screens)
Переходы между экранами должны обрабатываться плавно (fade/scale эффекты).
1. **Main Menu (`#menu-screen`):**
   - Кнопки: [Начать игру], [Лучшие результаты].
   - Интерактивность: Сложные hover-эффекты, реагирующие на наведение.
   - Фон: Глубокая темная тема с анимированными элементами (сетка или digital-паттерны).
2. **Game Screen (`#game-screen`):**
   - Игровое поле с неоновой или футуристичной рамкой.
   - Минималистичный, но стильный HUD поверх экрана или сбоку (Score / Best Score).
   - Модальное окно "Game Over" с блюром заднего фона (backdrop-filter).

## 4. Visual Rendering Rules (Canvas)
- **Snake:** Динамическое градиентное тело. Голова должна иметь четкий визуальный акцент (направленный свет или кибер-глаза). Плавное движение без "прыжков" по сетке (визуальная интерполяция).
- **Food:** Анимированный, пульсирующий объект.
- **Effects (Particles & Glow):** Обязательное свечение объектов (`shadowBlur`, `shadowColor`). При поедании еды генерируется эффект разлетающихся частиц. При столкновении (Game Over) — эффект "взрыва" или глитча змейки.

## 5. Development Guidelines
- **Clean Code:** Код должен быть готов к продакшену. Логика игры (Game Engine) должна быть отделена от логики отрисовки (Renderer) и интерфейса (UI Manager).
- **Responsiveness:** Идеальное масштабирование под любой размер экрана с сохранением пропорций Canvas.
- **Language:** Оставлять осмысленные комментарии к сложным алгоритмам (на русском языке).
